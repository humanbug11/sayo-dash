# 左右でダッシュ！

A / D を交互に押して加速する、PCブラウザ向けの2D横スクロールランゲームです。

## 技術構成

- HTML
- CSS
- TypeScript
- Phaser 3
- Vite

## 操作

| キー | 操作 |
| --- | --- |
| A | 左足 |
| D | 右足 |
| W | ジャンプ |
| S | スライディング |
| Space | ダッシュ |

A と D は同じキーを連打するのではなく、交互に押すことで加速します。入力間隔によって「パーフェクト」「グッド」「ミス」が変化します。

## ローカル起動

Node.js 20.19 以上を推奨します。

```bash
npm install
npm run dev
```

## ビルド

```bash
npm run build
```

ビルド結果は `dist/` に出力されます。
