# 左右でダッシュ！

A / D を交互に押して加速する、PCブラウザ向けの2D横スクロールランゲームです。

## 技術構成

- HTML
- CSS
- TypeScript
- Phaser 3
- Vite

## 操作

| キー | 操作 |
| --- | --- |
| A | 左足 |
| D | 右足 |
| W | ジャンプ |
| S | スライディング |
| Space | ダッシュ |
| H | 操作ガイドを3秒表示 |

A と D は同じキーを連打するのではなく、交互に押すことで加速します。入力間隔によって「PERFECT」「GOOD」「LATE」「MISS」が変化します。

## ローカル起動

Node.js 24 LTSを推奨します（ビルドのみは20.19以上でも使用できます）。

```bash
npm install
npm run dev
```

## ビルド

```bash
npm run build
```

ビルド結果は `dist/` に出力されます。

## 製品版UI改修

- ZIPのRAYNコンセプトから6ポーズの透過キャラクターを素材化
- 黒帯を使わない小型HUDと街／屋上の背景
- 操作ガイドは開始後3秒、Hで再表示
- PERFECT連続入力のコンボ、スピードライン、残像、ブースト、着地、コイン、ゴール演出
- ベストタイム、PERFECT率、最大コンボ、コイン、ミスを表示するリザルト
- Three.jsはタイトル背景の補助のみ

素材の採用・不足・代替箇所は [ASSET_UI_AUDIT.md](ASSET_UI_AUDIT.md)、生成プロンプトは [ASSET_GENERATION.md](ASSET_GENERATION.md)、検証内容は [UI_VALIDATION.md](UI_VALIDATION.md) を参照してください。
